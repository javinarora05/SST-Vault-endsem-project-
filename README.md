# 🚀 SST Pulse — Campus Event & Deadline Hub

> A full-stack React application that brings campus events, deadlines, club activities and social events into one place.

## 💡 Problem
Campus information is scattered across chats, emails, posters and word of mouth. SST Pulse provides a single, searchable place for students and organisers.

## ✨ Features
- Unified calendar
- Event categories and filters
- RSVP tracking with Firestore
- Weekend highlights
- Admin event management
- Email/password + Google authentication
- Search
- Dark mode
- Browser notifications
- Responsive UI
- Lazy-loaded routes
- Loading skeletons
- Framer Motion interactions

## 🚀 Setup
```bash

cd SST-Vault-endsem-project-
npm install
npm run dev
```

Create a `.env` file with the required Firebase `VITE_` variables.
